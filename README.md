# facet

Практика подготовки документов предпроектного и проектного анализа — требования,
технический дизайн, дискавери, исследования и статьи, разовые документы — на Dynamic
Workflows Claude Code с собственными агентами.

Грань за гранью: один тип документа — один профиль, один эталон, одна форма круга правки.
Линия проектов: prism → spectra → loom → refract → collimator → facet. Пять оркестраторов
переписаны за три месяца; шестой не пишется.

**Читать первым: [`SPEC.md`](SPEC.md)** — решения, уровни тяжести, конвейеры, план работ.

## Три уровня тяжести

| Уровень | Что | Как исполняется |
|---|---|---|
| 1 | Разовые: памятка, повестка, письмо, TCO, обзор решения, бриф | обычная сессия + профиль + подагенты писатель/критик |
| 2 | Профильные с кругами: gap-анализ, роли и сценарии, вопросы к архитектуре | скилл `/doc <тип> <папка>`, 1–2 круга критика |
| 3 | Тяжёлые конвейеры: требования, дизайн, статья, иллюстрации | сохранённый скрипт Dynamic Workflow в `.claude/workflows/` |

Хочу документ типа X → `docs/document-types.md` (появится на шаге 2 плана; до тех пор —
таблица конвейеров в `SPEC.md` §4).

## Что здесь есть

- `.claude/workflows/` — скрипты конвейеров уровня 3, написаны руками;
- `library/agents/` — источник правды по 28 агентам; `.claude/agents/` из него генерируется;
- `.claude/skills/<тип>-profile/` — профили типов документов, предзагружаются писателю и
  критику одного типа;
- `tools/` — детерминированные линейки: гейт, ведомость кругов, перечисление, публикация;
- `docs/decisions/` — разборы и ретроспективы с датами.

## Чего здесь нет

Кода оркестрации. Ни планировщика, ни леджера, ни рантайма, ни компилятора скриптов —
агентов запускает Claude Code. Компилятор `pipeline.yaml`, ради которого начинался
collimator, не достроен и не достраивается: скрипты руками — состояние, а не этап.

## Команды

```bash
uv sync --extra dev
uv run pytest                                          # без сети и без LLM
uv run python -c "from pathlib import Path; from collimator.emit_agents import emit_all; emit_all(Path('library/agents'), Path('.claude/agents'), Path('.claude/skills'))"
node tools/dry_run.mjs .claude/workflows/<скрипт>.js ok  # прогон на заглушках до живого запуска
```

Полный список и правила — в `CLAUDE.md`. Питоновый пакет пока называется `collimator`:
переименование — отдельный шаг (`SPEC.md` §9, §13).
